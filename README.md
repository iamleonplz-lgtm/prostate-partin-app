# 攝護腺癌分期決策助手

結合 NCCN / EAU 風險分組、骨髍掃描適應症，以及 Johns Hopkins **Partin Tables（2013）**，用來快速判斷：

- 新診斷攝護腺癌要不要做骨髍掃描
- 能否討論達文西根除術
- 器官侾限 / 被膜外 / 精囊 / 淋巴結的 Partin 預測機率

**僅供醫師臨床對照，不是醫囑。**
